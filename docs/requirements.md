# SecureReview AI — Project Requirements

## Project Goal
Compare AI-based code review tools with traditional
static analysis tools for identifying software
security vulnerabilities.

## Functional Requirements
1. Analyze code samples with known vulnerabilities.
2. Record findings from AI review tools.
3. Record findings from static analysis tools.
4. Compare findings with labeled vulnerability data.
5. Summarize detection results.

## Nonfunctional Requirements
- Reproducibility
- Maintainability
- Security
